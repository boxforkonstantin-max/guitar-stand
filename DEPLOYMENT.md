# Публикация конструктора

- Репозиторий: https://github.com/boxforkonstantin-max/guitar-stand
- Выбранный бесплатный хостинг: GitHub Pages, ветка main, корень.
- Ожидаемый адрес: https://boxforkonstantin-max.github.io/guitar-stand/
- Публикуются только код приложения и воспроизводимые файлы геометрии. Исходные пользовательские фотографии, приватные документы, секреты и соседние проекты не входят в Git.
- Статическое приложение; рабочих БД и серверного состояния нет. Откат — точный предыдущий Git commit. Изменения положений в браузере локальны и не сохраняются на сервере.
- R6: по просьбе владельца K и Katana возвращены в горизонтальное положение 0°. AIRSTEP центр Z45, прежний наклон 10°, упор U оставлен. Просвет у педали около 123 мм: удобство не подтверждено. Плашка AUX/USB/наушники 3,5 мм остаётся отложенной.
- Геометрия проекта не является допуском к изготовлению: нужно согласовать вентиляцию, крепёж, устойчивость, фактические габариты и эргономику.
