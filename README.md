# Гитарная стойка 590 x 420 x 800 мм

Версия R6. Полка Katana и усилитель снова горизонтальны (0°). AIRSTEP остаётся у переднего края на площадке 10°. До продолжения низа K от кнопок около 123 мм; над номинальным габаритом усилителя 124 мм. Удобство ноги и доступа к ручкам требует примерки. Вентиляция и силовые соединения ещё не согласованы: не выпуск в производство.

Размеры и положения хранятся в `design.json`. `generate_drawings.py` создаёт все форматы и `output/model.json`, который читает программа. `verify_exports.py` независимо сравнивает вершины DXF/SVG с моделью. Варианты `flow`, `lean`, `arc`; для последних двух файлы имеют суффиксы `_lean` и `_arc`.

## Быстрый запуск программы

Из папки `guitar-stand` выполните:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080/app/`. Интернет нужен только для загрузки Three.js с CDN.

## Производственные файлы

- `output/guitar_stand_drawings.pdf` - лист раскроя, чертеж боковины, сборочные виды и ведомость.
- `output/guitar_stand_layout_2440x1220.svg` - раскрой 1:1 в миллиметрах.
- `output/guitar_stand_layout_2440x1220.dxf` - раскрой для импорта в CAM.
- `output/guitar_stand_parts.dxf` - мастер-контуры деталей.
- `cad/guitar_stand.scad` - параметрическая 3D-сборка OpenSCAD.
- `output/verification.json` - машинная проверка границ, зазоров и площади.

## Статус

Это реальный размерный проект, но не разрешение на распил. Перед производством нужно подтвердить модель усилителя и снять контрольные габариты конкретного усилителя, контроллера и ноутбука. После подтверждения следует проверить посадку пазов на тестовом образце из-за фактической толщины фанеры и HPL.
